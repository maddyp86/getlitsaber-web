# getlitsaber-web

The Litsaber storefront. Next.js 14 on Shopify, instrumented with a weekly AI agent for conversion analysis.

> Litsaber is a festival accessory that happens to hit 510 carts. This repo is the website that says so.

## The build approach

This is a phased rebuild replatforming `getlitsaber.com` from WordPress/Avada to Next.js on Shopify. The guiding principle is **tool-per-phase** — no single tool owns the whole build:

| Phase | Tool | Job |
|-------|------|-----|
| Design | Figma | Visual + messaging source |
| Scaffold | Bolt | Figma → working Next.js |
| Build & integrate | Claude Code | Whole-repo agent for integration, fixes, ongoing dev |
| Commerce | Shopify Storefront API | Hosted checkout (Stripe is prohibited for vape) |
| Reviews | ReviewInfra | PDP reviews subsystem |
| Analytics | PostHog + Vercel Analytics + Supabase | Product + perf + agent-queryable events |
| Orchestration | n8n | Weekly production-agent cron |
| Agent reasoning | Claude API (tools) | The weekly conversion analyst |

See `docs/decisions/001-tool-stack-and-phasing.md` for the full rationale.

## Design system at a glance

**Palette (v0.3.0 hybrid):** deep purple-black canvas `#0A0518`, three decorative accents (cyan `#00E5FF`, magenta `#FF00E5`, purple `#9D5FFF`), and a dedicated CTA/conversion pink `#EC5793` (also the purple→pink gradient endpoint). Full tokens in `tokens.json`.

**Type:** Stellar (hero display), Monoton (accent words), Orbitron (sub-headings), Inter (body), Space Mono (labels/CTAs).

**Motion:** Framer Motion. Signature easing `cubic-bezier(0.16, 1, 0.3, 1)`, 700–900ms reveals, atmospheric layers (film grain, drifting starfield, blurred glow orbs). All motion honors `prefers-reduced-motion`. See `MOTION.md`.

**Rule:** No raw hex in components. Everything routes through named tokens in `tailwind.config.ts`.

## Environment variables

See `.env.example` for the full list. Grouped by service: Shopify, ReviewInfra, PostHog, HubSpot, Supabase, site config, age gate, feature flags. Key required vars:

- `NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN`, `NEXT_PUBLIC_SHOPIFY_STOREFRONT_TOKEN`
- `NEXT_PUBLIC_REVIEWINFRA_STORE_ID`
- `NEXT_PUBLIC_POSTHOG_KEY`
- `NEXT_PUBLIC_HUBSPOT_PORTAL_ID` + form IDs
- `NEXT_PUBLIC_AGE_GATE_COOKIE_NAME` / `_MAX_AGE_DAYS` / `_EXIT_URL`

Never commit `.env.local`. Production secrets live in Vercel's dashboard.

## Hosting & deployment

- **Host:** Vercel (Hobby tier at launch)
- **Registrar:** Namecheap. `getlitsaber.com` DNS points at Vercel during Phase 6/7 launch cutover. Until then, the live domain still runs the old WordPress site; the new build is verified on the Vercel preview URL.
- **Preview:** every PR auto-deploys to a unique Vercel preview URL
- **Production:** merging to `main` deploys to production

## Working with this repo via Claude Code

1. Install Claude Code (see Anthropic docs)
2. From the repo root: `claude`
3. Claude Code automatically reads `CLAUDE.md` for conventions, constraints, palette, and source-precedence rules
4. Ask for a plan before any non-trivial change. Approve the plan. Then let it execute.
5. Claude Code keeps `docs/working-memory.md` updated with decisions and story beats as it works.
